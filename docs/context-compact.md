# Compact Context：美团「试新」Demo

## 产品决策

- 核心问题：优质新店缺少可信证据，用户不敢拿一顿饭试错。
- 核心机制：自然语言需求 → 一主两辅推荐 → 三类证据 → 商家承诺锁单 → 餐后有效验证 → 证据成长 → 商家经营闭环。
- 三类证据：客观履约事实、标准化主观感受分布、真实行为证据。
- 治理原则：小样本必须明示；负向反馈仍奖励；争议先核验再计入；AI 不生成事实指标。

## 技术与演示边界

- React + Vite + TypeScript + HashRouter。
- 5 家虚拟店和 100 条合成验证数据，不接入美团内部数据库。
- AI 供应商中立；无密钥、失败或超时时自动使用本地规则。
- 状态保存在 `meituan-trial-demo:v1`，重置后回到 8 份验证。
- 路由：`/opening`、`/trial`、`/need`、`/recommendations`、`/store/:id`、`/checkout`、`/verify`、`/growth`、`/merchant`。
