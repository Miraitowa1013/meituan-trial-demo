# 试新首页筛选结构设计

## 目标

将首页的入口拆成四个互不冲突的维度，让用户可以组合选择“什么时候吃、吃什么、预算多少、按什么排序”。

## 信息结构

1. 用餐时段：早餐、午餐、晚餐、夜宵。单选，可与其他条件组合。
2. 菜品分类：全部、盖饭、面食、粥品、甜品等。单选，可与时段、价格和排序组合。
3. 快捷条件：25 元以内。独立开关。
4. 排序方式：综合推荐、离我最近、证据更充分。三者互斥。
5. 更多筛选：点击“筛选”后展开价格与距离面板，提供明确的应用和重置操作。

## 口径

- “证据更充分”表示有效验证样本更多。
- “高兑现”表示客观承诺兑现比例高，只作为店铺标签和详情指标展示。
- 删除首页独立的“高兑现新店”入口，避免与证据排序混淆。

## 交互

- 所有条件同步到 URL 查询参数，刷新后仍保留。
- 任意条件变化立即刷新店铺列表。
- 当前条件以选中态和摘要标签反馈。
- 空结果保留清除条件入口。

## 范围

本轮只调整试新首页筛选与结果列表，不增加社区、账号、积分或新的业务页面。
