# 美团「试新」AI 产品 Demo

「美团试新」解决用户第一次尝试新店时“信息不足、不敢下单”的问题：AI 把模糊需求翻译成商家可执行条件，商家把卖点发布为可验证承诺，承诺随订单锁定，完成订单的用户再用结构化验证共同生成可信证据。

> 美团试新，把新店第一次交易从“猜测”变成“验证”。

本项目是比赛演示环境，不连接美团生产系统，不产生真实支付或真实配送。店铺、订单与历史验证均为匿名沙盒数据。

## 在线体验

- 用户端：https://meituan-trial-demo.vercel.app/#/trial
- 商家经营台：https://meituan-trial-demo.vercel.app/#/merchant/store-beef-01
- 承诺方案工作台：https://meituan-trial-demo.vercel.app/#/merchant/store-beef-01/plans

在线版本默认使用规则兜底完成 AI 需求理解，不需要模型密钥。演示数据用于说明业务闭环，不代表美团真实经营数据。

## Windows 一键启动

环境要求：

- Windows 10/11
- Node.js 20.19 或更高版本
- 首次安装依赖时需要联网

启动步骤：

1. 解压整个压缩包，不能直接在压缩包预览窗口中运行。
2. 双击根目录的 `启动美团试新Demo.bat`。
3. 首次运行会自动执行 `npm install`，请等待服务窗口出现前端与 API 地址。
4. 浏览器会打开 `http://127.0.0.1:5173/#/trial`。
5. 使用期间不要关闭名为 “Meituan Trial Demo Service” 的服务窗口。

如果 5173 或 8787 端口已被占用，请先关闭旧的 Demo 服务窗口，再重新双击启动器。

## 推荐体验流程

### 第一段：用户完成一次可信试新

1. 进入“试新”频道，输入：“今晚加班，25 元以内，想吃牛肉饭，少油，汤别洒。”
2. 查看 AI 将需求拆为预算、品类、口味，并把“汤别洒”转换为商家可控的“独立密封分装”。
3. 比较推荐结果的匹配原因、有效样本量和风险。
4. 进入巷口牛肉饭，查看客观承诺、主观口味分布、规格声明和订单证据。
5. 选择试新套餐，确认当前发布版本及随单承诺，提交沙盒订单。
6. 在订单详情点击“模拟送达并进入餐后验证”。
7. 逐项确认客观承诺，补充少油感受和正常价复购意愿。
8. 提交后观察同一份证据从 8 笔成长到 9 笔。

### 第二段：商家核对同一份数据

1. 从证据成长页进入商家经营台。
2. 核对三项独立口径：
   - 独立密封分装：9/9
   - 少油感受符合：8/9
   - 正常价复购意愿：7/9
3. 查看 9/10 的可信成长进度、待核验争议和 AI 经营建议。

### 第三段：商家发布 V2，证明双端联动

1. 进入“方案与承诺”。
2. 点击“编辑为新版本”，生成 V2 草稿。
3. 点击“AI 识别可验证卖点”。
4. 商家确认或修改客观承诺、主观偏好、规格声明，并拒绝“好吃不踩雷”等不可验证宣传。
5. 调整试新价、每日名额和权益后发布 V2。
6. 返回用户端重新下单，新订单会锁定 V2；此前 V1 订单仍保持原快照。

## 产品与数据边界

- AI 负责理解语言和提取候选，不替用户或商家编造证据。
- 客观承诺只包含商家可控制、用户可观察的出餐事实。
- “少油”等主观感受形成分布，不进入客观赔付口径。
- “商家标称牛肉 80g”等规格保留来源，但不让普通用户承担称重核验。
- 未兑现反馈进入待核验，核验完成前不直接降低商家客观兑现率。
- 用户端和商家端读取同一数据库聚合结果，页面不各自拼一套数字。
- 10 份成长门槛仅用于 Demo 说明机制；真实上线应由样本置信度、品类、区域与风险动态判断。

## 技术结构

- 前端：React 19、Vite、TypeScript、TanStack Query
- 后端：Hono、Node.js
- 数据库：libSQL / SQLite、Drizzle ORM
- AI：兼容 DeepSeek Chat Completions API；默认使用确定性规则兜底

数据库首次启动时会自动执行迁移，并在空数据库中加载演示数据，无需单独安装数据库软件。

## AI 配置（可选）

不配置任何 API Key，也能完整演示需求理解和商家卖点分类。

如需使用 DeepSeek，将 `.env.example` 复制为 `.env`：

```env
LLM_PROVIDER=deepseek
DEEPSEEK_API_KEY=你的密钥
AI_BASE_URL=https://api.deepseek.com
AI_MODEL=deepseek-chat
```

模型请求失败或超时时，系统会自动回退到规则结果，不会阻断演示。请勿提交或转发包含真实密钥的 `.env`。

## 数据重置

页面中的“重置演示”会删除当前浏览器会话产生的订单、验证与争议，并恢复初始证据账。商家已发布方案属于全局沙盒供给配置；如需完全恢复 V1，可删除 `data/trial-demo.db` 后重新启动。

## 常见问题

### 双击启动器后页面打不开

确认已经把压缩包完整解压、Node.js 版本符合要求，并保持服务窗口开启。如果此前启动过 Demo，请先关闭旧服务窗口，避免端口占用。

### 下单后没有看到验证入口

在订单详情点击醒目的“模拟送达并进入餐后验证”，系统会自动推进沙盒履约状态。

### 没有 DeepSeek API Key 能否参赛演示

可以。规则兜底输出与模型输出使用同一结构，主流程不会依赖外部网络。
